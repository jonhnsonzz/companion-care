# CompanionCare 陪诊守护 🏥

**子女视角的陪诊服务平台**

> 你在1000公里外，妈妈在老家生病了。陪诊守护，让子女安心。

CompanionCare 是一款专为异地子女设计的陪诊服务平台。基于 Flask 后端构建，融合 AI 智能匹配、复诊提醒与健康档案管理，让子女即使远在千里之外，也能随时掌握父母的就诊动态。

---

## 🔍 痛点

- **异地子女无法陪护** — 工作繁忙、距离遥远，难以请假陪同老人就医
- **老人就医困难** — 挂号、问诊、缴费、取药流程复杂，老年人难以独自应对
- **服务缺乏保障** — 现有陪诊服务缺少审核、保险与售后追踪
- **情感负担** — 子女因无法陪伴而产生愧疚与焦虑

---

## ✨ 功能特点

### 🧠 情感定位
- **不是陪诊平台，是子女的「安心代理」**
- 目标用户：异地子女（付款者）× 老年患者（使用者）
- 核心卖点：让子女安心，不只是帮老人看病

### 🎯 AI 智能匹配
- 老人健康档案（病史 + 常去医院 + 过敏药物）
- 陪诊师能力画像（擅长科室 + 好评率 + 响应速度）
- 医院实战攻略（各医院陪诊技巧自动积累）

### 🛡️ 风控保障
- 陪诊服务免责协议（白纸黑字写清服务范围）
- 职业责任险（每次陪诊自动投保）
- 陪诊师实名认证 + 健康证核验

### 🔄 复购提醒
- AI 自动计算下次复查时间
- 系统主动推送复诊提醒给子女
- 陪诊师长期绑定，复购无需重新匹配

## 🚀 快速开始

### 环境要求
- Python 3.8+
- DeepSeek API Key（或其他兼容 LLM）

### 安装

```bash
# 克隆仓库
git clone https://github.com/jonhnsonzz/companion-care.git
cd companion-care

# 安装依赖
pip install -r requirements.txt

# 配置
cp .env.example .env
# 编辑 .env，填入 DEEPSEEK_API_KEY

# 运行
python app.py
```

浏览器打开 [http://localhost:5000](http://localhost:5000)

## 🤖 AI 驱动场景

1. **智能匹配** — 根据老人病史 + 医院 + 科室，匹配最擅长该领域的陪诊师
2. **复诊提醒** — AI 自动计算下次复查时间，系统主动推送提醒给子女
3. **服务辅助** — 陪诊师接单后自动收到该医院的实战技巧（来自历史服务积累）
4. **健康档案** — 每次服务后更新老人档案，画像越来越精准

## 🌐 部署

### Docker
```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
EXPOSE 5000
CMD ["python", "app.py"]
```

### Railway / Render / 任意云服务器
设置环境变量 `DEEPSEEK_API_KEY`，直接部署即可。
